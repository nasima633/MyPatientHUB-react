# MyPatientHUB React

A React-based healthcare dashboard for **MyPatientHUB**, converted from the original HTML, CSS, and JavaScript project.

The project was rebuilt with **React and Vite** while preserving the original design, layout, and main functionality.

## 🚀 Technologies Used

* React
* JavaScript
* HTML
* CSS
* Vite
* Git
* GitHub

## 📌 Features

* Login page
* Dashboard page
* Responsive sidebar navigation
* Header with search functionality
* Sidebar navigation filtering
* Find Doctor page
* Find Clinic page
* Clinic search and location filtering
* Responsive design
* Logout functionality
* Footer
* Mobile sidebar menu

## 🧩 React Components

The application uses reusable React components for the main dashboard layout:

* **Header** — page title, search, logout, settings, and notifications
* **Sidebar** — navigation and navigation filtering
* **Footer** — application footer and links
* **PageLayout** — combines the header, sidebar, page content, and footer

## 📄 Pages

### Login

The login page provides:

* Email/phone input
* Password input
* Remember Me option
* Social login buttons
* Sign In
* Sign Up
* Forgot Password

### Dashboard

The main dashboard of MyPatientHUB.

### Find Doctor

Allows users to:

* Search for doctors
* Select healthcare services
* Select specialties
* Select location
* View search-related interactions

### Find Clinic

Allows users to:

* Search clinics by name
* Filter clinics by location
* View available clinics
* View clinic services
* View clinic ratings

## ▶️ Run the Project

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

## 🛠️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
